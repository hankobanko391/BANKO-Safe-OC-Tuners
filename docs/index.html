Built-In Hardware Safety Guardrails (Both Editions)

Zero Voltage Sliders Core voltage adjustment is omitted entirely to eliminate over-volting risk on mobile GPUs.
82°C Thermal Cut-Off Polls GPU temperature every 1000ms and automatically reverts to Stock / Eco Mode above 82°C.
Safe Offset Ceilings Balanced Boost (+75/+150 MHz) and Max Safe OC (+120/+250 MHz) via NVAPI / nvidia-smi + Windows Power fallback.
1-Click Reset to Stock Prominent Reset button immediately restores factory clocks (-rgc/-rmc) and Balanced power plan.
